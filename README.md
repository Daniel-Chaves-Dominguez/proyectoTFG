# María Chaves - Laser hair removal and beauty treatments

Website for María Chaves' laser hair removal and beauty centre in Puerto Real (Cádiz).

Project made by **Daniel Chaves Domínguez** (2nd year DAW) with **HTML, CSS and JavaScript**, without frameworks.

## How to view it

Open `index.html` in the browser, or use the **Live Server** extension for VS Code.
